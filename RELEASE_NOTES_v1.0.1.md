# Quick File Organizer v1.0.1

This maintenance update improves display compatibility and the overall Windows desktop experience.

## Fixed

- Improved layout compatibility across different Windows DPI scaling settings.
- Fixed clipped or compressed controls on some laptop displays.
- Improved spacing and height in the File Types section.
- Improved button sizing for both Chinese and English text.

## Improved

- The application window can now be resized and maximized.
- Vertical scrolling is available as a fallback on smaller displays.
- Added a custom Windows application icon.
- Updated project metadata and repository information.

## Download

Download the portable ZIP, extract it, and run `QuickFileOrganizer.exe`.

No installation or separate .NET runtime is required.
