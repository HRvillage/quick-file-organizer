# Quick File Organizer v1.0.0

First public release of Quick File Organizer, a lightweight and portable Windows batch file renaming utility.

## Highlights

- Combine two optional custom names, date, and sequence number
- Use today's date, a manual date, or each file's created/modified time
- Select files by grouped image, video, document, and archive formats
- Preview the generated filename before applying changes
- Detect target filename conflicts without overwriting existing files
- Undo the most recent successful rename operation
- Switch between Traditional Chinese and English
- Run as a portable, self-contained Windows application

## 主要功能

- 可組合兩組自訂名稱、日期與流水號
- 日期可使用今日、手動日期、檔案建立時間或修改時間
- 依圖片、影片、文件與壓縮檔分類選取
- 執行前即時預覽新檔名
- 檢查同名衝突，不覆蓋既有檔案
- 可復原上一次成功重新命名
- 支援繁體中文與英文介面
- 可攜式、免安裝 Windows 工具

## Download

Download `QuickFileOrganizer_v1.0.0_Portable.zip`, extract it, and run `QuickFileOrganizer.exe`.

下載 `QuickFileOrganizer_v1.0.0_Portable.zip`，解壓縮後執行 `QuickFileOrganizer.exe`。

## Requirements

- Windows 10 or Windows 11, 64-bit
- No separate .NET installation is required for the portable release
