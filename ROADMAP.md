# Roadmap / 開發方向

Quick File Organizer is intentionally focused. Planned work prioritizes reliability and practical usability over feature count.

Quick File Organizer 刻意維持單一用途。後續工作會優先處理可靠性與實際操作需求，而不是追求功能數量。

## Maintenance Priorities / 維護重點

- Verify behavior across common Windows 10 and Windows 11 display scaling settings
- 持續確認 Windows 10、Windows 11 與常見顯示縮放下的介面表現
- Improve error messages for locked, unavailable, or permission-restricted files
- 改善檔案鎖定、無法存取或權限不足時的錯誤訊息
- Expand test coverage for rename conflicts and partial undo cases
- 擴充檔名衝突與部分復原情境的測試
- Review additional common file extensions based on actual requests
- 依實際需求評估其他常用副檔名

## Possible Future Enhancements / 可能的後續功能

- Optional custom date display formats
- 可選擇其他日期顯示格式
- A detailed rename preview dialog when full file-by-file review is needed
- 在需要逐筆確認時提供完整預覽視窗
- Optional dark appearance if it can remain compact and dependency-free
- 在不增加複雜依賴的前提下評估深色介面
- Signed release packages when a suitable code-signing process is available
- 在具備合適程式簽章流程後提供簽章版本

## Out of Scope for Now / 目前不規劃

- Recursive subfolder processing
- 遞迴處理子資料夾
- Folder renaming
- 資料夾重新命名
- Complex template management
- 複雜模板管理
- Cloud synchronization or accounts
- 雲端同步或帳號系統
- Broad file-management features unrelated to renaming
- 與重新命名無關的大型檔案管理功能
