# 開發歷程

## 專案緣起

Quick File Organizer 起源於一個常見但容易耗費時間的工作：將同一批圖片、影片或文件依照固定規則重新命名(尤其是從Line的相簿批量下載活動照片來整理的時候)。

一般檔案總管適合處理少量檔案，但在需要加入日期、兩組自訂名稱、連續流水號或依時間排序時，手動作業容易出錯。

本專案因此以「快速、直覺、免安裝、安全復原」為核心，目標不是建立功能繁多的檔案管理套件，而是提供一個打開後能立即完成工作的單一用途工具。

## 設計原則

### 單頁完成

主要操作集中在同一畫面，不使用多層選單或分頁。正式版採固定尺寸，確保常用功能與操作按鈕能同時呈現。

### 清楚而非複雜

命名規則維持在名稱 1、名稱 2、日期與流水號四個基本元素。空白欄位會自動略過，減少不必要的模板管理功能。

### 降低誤操作

檔案類型每次啟動時預設全部關閉；執行前提供即時預覽；重新命名前檢查檔名衝突；完成後保留一次復原紀錄。

### 可攜與本機優先

工具採可攜式封裝，設定保存在程式旁的 `Data` 資料夾。所有檔案處理都在本機完成，不需要登入帳號或連線服務。

## 功能演進

### 初期原型

第一階段完成資料夾選擇、基本自訂名稱、日期前綴與流水號，並驗證依檔案建立時間排序後批次重新命名的核心流程。

### 功能完善

後續加入第二組自訂名稱、日期位置、手動日期、檔案建立與修改時間來源、延續上次號碼、檔案類型篩選，以及完成後開啟資料夾。

### 安全性與可用性

為降低批次操作風險，加入重新命名前預覽、同名檔案檢查、兩階段暫存重新命名，以及「還原上一次」功能。檔案類型改以圖片、影片、文件與壓縮檔分類，讓不熟悉副檔名的使用者也能操作。

### 介面整理

介面由傳統 WinForms 預設外觀調整為卡片式配置，建立一致的按鈕層級、間距與配色，並加入中文與英文快速切換。經過不同螢幕解析度與顯示縮放測試後，正式版改採固定尺寸與無捲動設計，避免底部按鈕被裁切。

### v1.0.0

第一個公開版本統一版本號為 `v1.0.0`。公開前完成程式碼清理、雙語使用文件、開發紀錄、版本紀錄、可攜式建置流程與 GitHub 專案結構整理。

## 技術選擇

- C#
- .NET 8
- Windows Forms
- Self-contained single-file publish
- JSON 本機設定與復原紀錄

選擇 WinForms 的原因是啟動快速、Windows 整合直接、依賴少，並適合這類單一用途的輕量桌面工具。

## 後續方向

後續更新會優先處理實際使用中發現的相容性、檔案格式與操作體驗問題。新功能只有在不破壞單頁、輕量與直覺原則的前提下才會加入。
