# 開發沿革

## 專案起點

Quick File Organizer 起源於一個很常見但容易出錯的工作：把大量照片、文件、設計素材或其他檔案依照固定規則重新命名。Windows 檔案總管可以處理少量檔案，但當檔名需要日期、自訂名稱、流水號、檔案時間或分組規則時，手動處理很容易漏改、錯排或覆蓋。

因此，本專案的核心目標是：快速、清楚、安全、可攜。它不是大型檔案管理系統，而是一個專注於批次命名的 Windows 小工具。

## 設計原則

### 降低操作成本

主要流程集中在單一視窗中，使用者可以快速選擇資料夾、設定命名規則、選擇檔案類型、查看預覽並執行重新命名。

### 保持命名規則易懂

一般命名流程以名稱、日期與流水號為核心，並提供常用檔名格式。使用者不需要學習複雜模板，也能完成常見工作情境。

### 降低批次操作風險

程式在重新命名前提供預覽、檢查同名衝突、提示混合副檔名批次，並保留最近一次操作的還原紀錄。

### 本機與可攜優先

工具以可攜方式發佈，設定與還原紀錄儲存在程式旁的 `Data` 資料夾。所有檔案處理都在本機完成，不需要登入帳號或連線服務。

## 功能演進

### 初期原型

第一階段完成資料夾選擇、基本自訂名稱、日期、流水號，以及依檔案時間排序後批次重新命名的核心流程。

### v1.0.0

第一個公開版本統一版本號為 `v1.0.0`。此版本建立基本重新命名流程、預覽、還原、檔案類型篩選、可攜式發佈與 GitHub 專案文件。

### v1.0.1

此版本重點是 Windows 桌面相容性。主要改善不同 DPI 縮放與筆電工作區下的顯示問題，讓視窗可以調整大小與最大化，加入 AutoScroll 安全網，修正按鈕文字裁切、File Types 高度、圓角按鈕繪製殘影，並加入正式 Windows app icon。

### v1.1.0

此版本新增分組命名助手，用於施工紀錄、保險理賠、房仲空間、商品照片、醫療紀錄、Airbnb 房型與其他重複檔案組。它支援每組固定檔案數、同組相同或不同名稱、分組預覽、時間間隔異常提醒與分組日期標記。

同時，v1.1.0 擴充檔案類型支援，加入音訊、進階圖片、設計素材、CAD 圖面與 3D 模型分類。也加入 Any 模式，讓使用者可以在確認後處理未列入預設清單的檔案類型。

## 技術

- C#
- .NET 8
- Windows Forms
- Self-contained single-file publish
- 本機 JSON 設定與還原紀錄

WinForms 適合這個專案，因為它啟動快速、依賴少、Windows 整合直接，也符合此工具輕量、可攜、專注的方向。

## 後續方向

後續版本會優先處理真實使用中發現的相容性、命名彈性與操作安全需求。新增功能會以不增加過多操作成本為前提，避免工具變成複雜的大型檔案管理系統。
