# Quick File Organizer 使用指南

## 1. 啟動程式

執行發佈檔中的：

```text
QuickFileOrganizer.exe
```

程式旁的 `Data` 資料夾會保存偏好設定與最近一次重新命名紀錄。若還需要使用還原功能，請不要刪除這個資料夾。

## 2. 選擇資料夾

可以使用兩種方式：

- 點選 **選擇資料夾**。
- 將一個資料夾拖曳到主視窗。

程式只會處理所選資料夾第一層的檔案，不會重新命名子資料夾，也不會遞迴處理子資料夾中的檔案。

## 3. 設定一般檔名

### 名稱與日期

`名稱 1` 與 `名稱 2` 都可以留空。留空的欄位會自動略過，不會產生多餘分隔符號。

日期來源可選擇：

- 不加入日期
- 今天日期
- 手動輸入
- 檔案日期

檔案日期可以使用修改時間或建立時間。若檔案曾經下載、複製或匯出，建議先檢查 Windows 檔案內容中的時間是否符合預期。

### 檔名格式

檔名格式下拉選單提供常用組合，例如：

```text
名稱1_名稱2_日期_流水號
名稱1_名稱2_流水號_日期
日期_名稱1_名稱2_流水號
流水號_名稱1_名稱2_日期
```

也包含名稱接流水號、不加底線的格式，適合商品、案例或現場照片等常見命名方式。

### 流水號

- **起始號碼**：本次重新命名使用的第一個號碼。
- **流水號位數**：控制補零位數，例如 `001`。
- **接續相同命名設定的上一個號碼**：同一組命名設定下，從上次記錄的下一個號碼開始。

## 4. 選擇檔案類型

可選擇的分類包含：

- 圖片：JPG/JPEG、PNG、GIF、WEBP、BMP
- 影片：MP4、MOV、AVI
- 文件：PDF、Word、Excel、PowerPoint、TXT
- 壓縮檔：ZIP、RAR、7Z
- 音訊：MP3、WAV、OGG、WMA、AAC
- 進階圖片：HEIC、TIFF、RAW
- 設計素材：PSD、AI、INDD、Sketch、FIG
- CAD 圖面：DWG、DWF、DXF
- 3D 模型：STEP、IGES、STL、3DS

勾選分類會選取該分類中的所有格式，也可以只勾選個別格式。檔案類型選項在重新啟動後會恢復未勾選狀態，以降低誤操作風險。

## 5. 使用 Any 模式

若要處理的副檔名不在預設清單中，可以勾選 **Any：包含資料夾內所有檔案**。

Any 模式會包含所選資料夾內所有非隱藏、非系統檔案，不再依下方檔案類型清單篩選。啟用時程式會跳出確認視窗，請確認資料夾內容與預覽後再執行。

## 6. 使用分組命名助手

點選 **分組命名...** 可開啟分組命名助手。

適合情境包含：

- 工程現場：施工前、施工中、施工後
- 保險理賠：車頭、車尾、左側、右側
- 房仲：客廳、餐廳、廚房
- 電商商品：正面、背面、側面
- 醫療紀錄：術前、術中、術後
- Airbnb：客廳、房間、浴室

基本步驟：

1. 設定每組檔案數量。
2. 選擇排序依據。
3. 設定主體前綴、起始編號、位數與分隔符。
4. 選擇每組使用相同名稱或不同名稱。
5. 需要時加入日期標記，並選擇日期位置。
6. 檢查分組預覽與時間間隔提醒。
7. 確認無誤後執行重新命名。

時間間隔提醒可以協助發現可能少拍、多放或排序異常的檔案。它不會自動修正分組，使用者仍需要回到資料夾檢查檔案是否完整。

## 7. 檢查預覽並重新命名

執行前請確認：

- 資料夾正確。
- 命名格式正確。
- 日期來源與流水號正確。
- 檔案類型或 Any 模式符合本次目標。
- 預覽中沒有非預期檔案。

若批次中包含多種副檔名，程式會要求再次確認後才會繼續。

## 8. 還原上一次

點選 **還原上一次** 可復原最近一次成功的重新命名。

注意：

- 只保留最近一次成功操作。
- 若檔案已被移動、刪除或再次改名，可能無法完整還原。
- 新的成功重新命名會取代前一次還原紀錄。

## 9. 切換語言

右上角可切換中文與英文。主視窗切換語言後，分組命名助手也會使用相同語言顯示。
