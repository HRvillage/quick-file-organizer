# Quick File Organizer 使用教學

## 1. 啟動工具

解壓縮下載的 Portable ZIP 後，執行：

```text
QuickFileOrganizer.exe
```

程式旁的 `Data` 資料夾會保存偏好設定與上一次重新命名紀錄，請勿在需要復原前刪除它。

## 2. 選擇檔案資料夾

可以使用下列任一方式：

- 按下「選擇資料夾」。
- 將一個資料夾拖曳到程式視窗。

工具只處理所選資料夾第一層的檔案，不會進入子資料夾，也不會重新命名資料夾本身。

## 3. 設定新檔名

### 名稱 1 與名稱 2

兩個欄位都可以留空。空白欄位會自動略過，不會產生重複底線。

範例：

```text
名稱 1：Bandai
名稱 2：OPCG
```

### 日期來源

- **不加入日期**：檔名中不放日期。
- **今日日期**：使用執行當天日期。
- **手動輸入**：自行選擇指定日期。
- **檔案時間**：依每個檔案的建立時間或修改時間產生日期。

部分相機、手機或下載檔案的實際時間可能顯示在「修改時間」，建議先確認 Windows 檔案內容中的時間資訊。

### 日期位置

- **名稱之前**：`20260717_Bandai_OPCG_001.jpg`
- **名稱之後**：`Bandai_OPCG_20260717_001.jpg`

### 流水號

- **起始號碼**：本次第一個檔案要使用的號碼。
- **流水號位數**：例如三位數會顯示為 `001`、`002`。
- **延續相同命名組合**：使用同一組名稱設定時，自動從上次最後號碼的下一號開始。

## 4. 選擇檔案類型

檔案類型分為：

- 圖片：JPG/JPEG、PNG、GIF、WEBP、BMP
- 影片：MP4、MOV、AVI
- 文件：PDF、Word、Excel、PowerPoint、TXT
- 壓縮檔：ZIP、RAR、7Z

勾選分類名稱會一次選取該分類全部格式。取消分類名稱則會全部取消。也可以只勾選個別副檔名。

每次重新啟動工具時，檔案類型預設全部不勾選，以降低誤操作風險。

## 5. 查看預覽

預覽區會依目前設定顯示一個新檔名範例。選擇有效資料夾與副檔名後，也會顯示符合條件的檔案資訊。

執行前請確認：

- 資料夾是否正確。
- 名稱與日期位置是否正確。
- 起始號碼與位數是否正確。
- 選取的檔案類型是否正確。

## 6. 開始重新命名

按下「開始重新命名」。程式會先檢查檔名衝突，再執行批次重新命名。

程式不會覆蓋已存在的同名檔案。若檢查到衝突，操作會停止並顯示提示。

完成後可按「開啟資料夾」查看結果。

## 7. 還原上一次

若最近一次重新命名有誤，按下「還原上一次」。

注意事項：

- 只能復原最近一次由本工具完成的重新命名。
- 若檔案已被刪除、搬移或再次改名，部分項目可能無法復原。
- 新一次成功重新命名會取代前一次復原紀錄。

## 8. 切換語言

右上角可在「中文」與「EN」之間快速切換。語言設定會保留至下次開啟。

## 9. 攜帶到其他電腦

請一起複製：

```text
QuickFileOrganizer.exe
Data\
```

如果不需要保留設定與復原紀錄，也可以刪除 `Data` 資料夾；程式下次啟動時會重新建立。
