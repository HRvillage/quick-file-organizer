# 常見問題

## 我需要安裝 .NET 嗎？

不需要。GitHub Releases 提供的發佈檔已包含執行所需環境，一般使用者只要下載並執行 `QuickFileOrganizer.exe`。

只有從原始碼自行建置時，才需要 .NET 8 SDK。

## 程式會上傳我的檔案或檔名嗎？

不會。所有處理都在本機完成，不需要帳號，也不會把檔案或檔名傳到線上服務。

## 為什麼檔案類型每次重新開啟都沒有勾選？

這是刻意設計的安全機制，避免使用者下次開啟程式時誤用上次的檔案類型設定，造成不預期的批次重新命名。

## Any 模式是做什麼的？

Any 模式用來處理不在預設清單中的副檔名。啟用後，程式會包含資料夾內所有非隱藏、非系統檔案，並在執行前跳出確認提醒。

使用 Any 模式時，請務必先確認資料夾內容與預覽結果，因為它不會依檔案類型篩選。

## 可以重新命名子資料夾裡的檔案嗎？

不行。目前只處理所選資料夾第一層的檔案，不會遞迴處理子資料夾。

## 可以重新命名資料夾本身嗎？

不行。目前版本只重新命名檔案。

## 建立時間與修改時間有什麼差別？

建立時間通常代表檔案進入目前磁碟或資料夾的時間，複製、下載或解壓縮後可能改變。修改時間通常代表檔案內容最後變更時間，有時更接近照片或文件的原始時間。

處理重要檔案前，建議先查看 Windows 檔案內容確認時間是否符合需求。

## 分組命名助手一定要用照片嗎？

不一定。它可以用於任何已被目前檔案類型設定包含的檔案，也可以搭配 Any 模式處理其他副檔名。它適合所有固定數量、重複命名規則的檔案組。

## 時間間隔提醒會自動修正錯誤分組嗎？

不會。時間間隔提醒只用來指出可能有少拍、多放、排序異常或無關檔案混入的地方。使用者需要回到資料夾確認檔案，移除或補齊後再重新預覽。

## 還原可以復原多次操作嗎？

不行。程式只保存最近一次成功重新命名的紀錄。

## 檔案被移動後還能還原嗎？

如果檔案被移動、刪除或再次重新命名，可能無法完整還原。程式會嘗試還原仍可找到的檔案，並回報結果。

## 為什麼 Windows 或防毒軟體會跳出提醒？

未簽章的獨立 Windows 應用程式有時會觸發 SmartScreen 或防毒軟體的信譽提醒。請只從本專案官方 GitHub Releases 下載，並確認版本來源。

## 可以放在 USB 隨身碟使用嗎？

可以，只要程式能寫入旁邊的 `Data` 資料夾。若位置是唯讀，偏好設定與還原紀錄可能無法保存。
