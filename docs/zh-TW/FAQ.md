# 常見問題

## 使用前需要安裝 .NET 或開發工具嗎？

不需要。GitHub Releases 提供的 Portable 版本會包含所需執行環境。一般使用者只需要解壓縮並執行 EXE。

只有自行編譯原始碼時才需要安裝 .NET 8 SDK。

## 工具會上傳我的檔案或檔名嗎？

不會。所有處理都在本機完成，工具不需要帳號，也不會把檔案或檔名傳送到網路。

## 為什麼每次啟動後副檔名都沒有勾選？

這是刻意的安全設計，避免使用者開啟程式後直接對錯誤類型的檔案執行批次操作。

## 可以處理子資料夾嗎？

目前不會進入子資料夾，只處理所選資料夾第一層的檔案。

## 可以重新命名資料夾嗎？

目前只處理檔案，不會修改資料夾名稱。

## 建立時間與修改時間有什麼差別？

建立時間通常代表檔案進入目前磁碟或資料夾的時間；複製、下載或解壓縮可能使它改變。修改時間通常代表檔案內容最後被修改的時間，部分相機圖片或下載檔案的原始日期可能保留在此欄位。

請先查看 Windows 檔案內容，選擇最符合實際需求的時間來源。

## 還原功能可以復原很多次嗎？

不能。工具只保存最近一次成功重新命名的紀錄。

## 如果檔案在重新命名後被搬走，還能還原嗎？

被搬移、刪除或再次改名的檔案可能無法還原。工具會嘗試處理仍可找到的項目並回報結果。

## 為什麼程式被防毒軟體提醒？

未簽章的小型自製 Windows 程式有時可能被 SmartScreen 或防毒軟體要求額外確認。請只從本專案的 GitHub Releases 下載，並核對版本與檔案來源。

正式建置不使用 UPX 或其他執行檔壓縮工具，以降低誤判風險。

## 可以把程式放在 USB 或網路磁碟嗎？

可以，但程式需要能在旁邊的 `Data` 資料夾寫入設定。若位置為唯讀，偏好設定與復原紀錄可能無法保存。
