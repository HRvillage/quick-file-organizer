# Contributing

Contributions that improve reliability, accessibility, documentation, or focused batch-renaming workflows are welcome.

Before opening a pull request:

1. Keep the application focused on file renaming.
2. Preserve the compact single-screen interface.
3. Avoid new runtime dependencies unless clearly justified.
4. Do not weaken conflict detection or undo safety.
5. Update relevant English and Traditional Chinese documentation.
6. Build the Release configuration and test the portable output on Windows.

For larger changes, open an issue first to describe the intended workflow and interface impact.
