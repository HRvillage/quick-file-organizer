Quick File Organizer v1.0.1
檔案整理工具

1. Run QuickFileOrganizer.exe directly. No installation is required.
2. The Data folder stores local settings and the last rename record.
3. Keep QuickFileOrganizer.exe and the Data folder together when moving the app.

使用方式：
1. 直接執行 QuickFileOrganizer.exe，不需要安裝。
2. Data 資料夾會保存本機設定與上一次重新命名紀錄。
3. 搬移程式時，請將 EXE 與 Data 資料夾一起移動。
