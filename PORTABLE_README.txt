Quick File Organizer v1.1.0
檔案快速整理器

1. Run QuickFileOrganizer.exe directly. No installation is required.
2. The Data folder stores local settings and the last rename record.
3. Keep QuickFileOrganizer.exe and the Data folder together when moving the app.
4. Use Any mode only when you want every non-hidden, non-system file in the folder to be included.

使用方式：
1. 直接執行 QuickFileOrganizer.exe，不需要安裝。
2. Data 資料夾會儲存本機設定與上一次重新命名紀錄。
3. 移動程式時，請將 QuickFileOrganizer.exe 和 Data 資料夾放在一起。
4. Any 模式會納入資料夾內所有非隱藏、非系統檔案，請只在確定需要時使用。
